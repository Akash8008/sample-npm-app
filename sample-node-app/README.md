# Sample Node App

A simple Node.js Express application created for DevOps CI/CD practice.

## Project structure

- `src/`
  - `app.js` - Express application and routing setup.
  - `server.js` - Starts the app when run directly.
  - `routes/` - Express route modules for `/health` and `/version`.
- `tests/` - Jest tests for endpoints.
- `dist/` - Build output generated by `npm run build`.
- `package.json` - npm package definition, scripts, and dependencies.
- `package-lock.json` - exact dependency versions for reproducible installs.
- `.gitignore` - files and folders excluded from version control.

## Available scripts

- `npm install` - installs dependencies and generates `package-lock.json`.
- `npm test` - runs Jest unit tests.
- `npm run build` - generates the `dist/` folder from `src/`.
- `npm start` - runs the app from `dist/`.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Build the application:

```bash
npm run build
```

3. Run the app:

```bash
npm start
```

4. Open in browser:

```text
http://localhost:3000
```

## Endpoints

- `GET /` — returns `Welcome to DevOps CI/CD Demo`
- `GET /health` — returns `{ "status": "UP" }`
- `GET /version` — returns `{ "version": "1.0.0" }`

## How this fits into DevOps practice

- `package.json` and `package-lock.json` provide dependency and build metadata.
- `src/` contains the application source code.
- `tests/` contains automated unit tests that CI pipelines should run.
- `dist/` is the build artifact output that can be uploaded and deployed.
- `.gitignore` keeps local files from polluting source control.
